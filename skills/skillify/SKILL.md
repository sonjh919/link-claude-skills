# Skillify: 반복 작업 스킬화 추천

사용자가 방금 마친 작업을 돌아보고, 반복된 패턴을 찾아 커스텀 스킬로 만들면 좋을 작업을 추천한다.

## 분석 절차

### 1단계: 현재 대화 분석

현재 대화에서 다음을 파악한다:

- **도구 사용 시퀀스**: 어떤 도구들이 어떤 순서로 반복 사용되었는가
- **파일 작업 패턴**: 유사한 구조의 파일을 반복 생성/수정했는가
- **워크플로우 반복**: 탐색→수정→테스트 같은 흐름이 여러 번 나타났는가
- **도메인 지식 반복**: 특정 분야의 지식이 반복적으로 필요했는가
- **수동 작업**: 자동화할 수 있었던 수동 단계가 있었는가

### 2단계: 스킬화 후보 식별

다음 기준으로 반복 패턴을 탐지한다:

- 같은 도구 조합이 **2회 이상** 유사하게 반복된 경우
- 유사한 파일 구조/형식을 반복 생성한 경우 (예: 매번 같은 템플릿으로 파일 작성)
- 동일한 멀티스텝 워크플로우를 여러 번 수행한 경우
- 특정 컨벤션이나 도메인 규칙을 매번 설명해야 했던 경우
- 외부 도구/API를 특정 패턴으로 반복 호출한 경우

핵심 질문: "이 작업을 앞으로도 반복한다면, 어떤 스킬이 있으면 한 번에 끝낼 수 있을까?"

### 3단계: 제안 선별

다음 기준으로 제안을 필터링한다:

- **자동화 효과**: 스킬로 만들면 얼마나 시간이 절약되는가
- **재사용 빈도**: 앞으로도 자주 반복될 작업인가
- **구현 난이도**: SKILL.md로 구현 가능한 수준인가

제안은 **최대 3개**로 제한한다. 실제로 스킬화할 가치가 있는 것만 추천한다.

### 4단계: 마크다운 파일 생성

현재 작업 디렉토리에 `skillify-YYYY-MM-DD.md` 파일을 생성한다.
같은 날짜의 파일이 이미 있으면 `skillify-YYYY-MM-DD-2.md`처럼 번호를 붙인다.

파일 형식:

```markdown
# 스킬화 추천

> 생성일: YYYY-MM-DD

## 작업 요약
이번 세션에서 수행한 작업을 2-3문장으로 요약.

## 발견한 반복 패턴
- **패턴명**: 어떤 작업이 반복되었는지 간단히

## 스킬화 제안

### 1. 제안 스킬 이름
- **자동화 대상**: 어떤 반복 작업을 자동화하는지
- **트리거 예시**: 어떤 상황/명령어에서 이 스킬이 호출될지
- **예상 SKILL.md 골격**:
  ```
  간단한 구조 스케치 (주요 섹션과 핵심 지시사항)
  ```
- **예상 효과**: 시간 절약, 일관성 확보 등 구체적 이점

### 2. 제안 스킬 이름
...

## 바로 시작하기
가장 쉽게 만들 수 있는 스킬 하나를 골라, 구체적인 첫 단계를 제안.
```

### 5단계: 텍스트 응답

파일 생성 후 간단한 텍스트 요약을 출력한다:

- 핵심 제안 1-2개를 한 줄씩
- 생성된 파일 경로

장황하게 설명하지 않는다. 자세한 내용은 파일에 있다.

## 주의사항

- 일회성 작업은 스킬화 대상이 아니다. 앞으로 반복될 가능성이 높은 것만 추천한다.
- 이미 존재하는 스킬이나 내장 기능으로 해결 가능한 경우, 새 스킬 대신 기존 것을 안내한다.
- "~해야 합니다" 같은 지시적 톤이 아니라, "~로 만들면 다음에 더 빠르게 할 수 있어요" 같은 제안 톤을 사용한다.
- 예상 SKILL.md 골격은 완성본이 아닌 출발점으로, 사용자가 skill-creator로 발전시킬 수 있도록 한다.
